# Portfolio (Next.js)

An earlier version of my personal portfolio website, built with **Next.js**, **TypeScript**, and **Tailwind CSS**, and deployed on **Fly.io**.

> My current academic website is at **[itsazibfarooq.github.io](https://itsazibfarooq.github.io)** ([source](https://github.com/itsazibfarooq/itsazibfarooq.github.io)).

## Run Locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Deploy

The repository includes a `Dockerfile` and `fly.toml` for deployment with `fly deploy`.
